왜 AI 면접코치인가?

학생부종합 전형 면접을 완벽하게 대비하세요

AI 맞춤형 질문 생성

Claude AI가 학생부(생기부) 내용을 심층 분석하여 실제 면접에 나올 법한 질문 10~100개를 자동 생성합니다.

모범 답변 가이드

각 질문마다 학생부 활동을 활용한 모범 답변 예시, 핵심 포인트, 차별화 전략을 제공합니다.

음성 인식 연습

Web Speech API를 활용한 실전 면접 연습으로 답변 길이와 완성도를 실시간으로 피드백합니다.

카테고리별 분류

전공적합성, 학업역량, 인성, 발전가능성으로 질문을 분류하여 체계적인 준비가 가능합니다.

북마크 & 검색

중요한 질문을 북마크하고, 키워드 검색으로 원하는 질문을 빠르게 찾을 수 있습니다.

인쇄 & 다운로드

생성된 모든 질문과 답변을 텍스트 파일로 다운로드하거나 깔끔하게 인쇄할 수 있습니다.

사용 방법

4단계로 간편하게 면접 준비를 시작하세요

1

로그인 & API 키 설정

회원가입 후 Anthropic Claude API 키를 설정합니다

2

대학/학과/전형 선택

지원할 대학, 학과, 전형을 선택하고 질문 개수를 정합니다

3

학생부(생기부) 입력

개인정보를 제거한 활동 내용을 입력합니다

4

질문 생성 & 연습

AI가 질문과 답변을 생성하면 음성으로 연습합니다
