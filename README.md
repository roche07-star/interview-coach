## 📋 서비스 소개

2027학년도 대학 입시 학생부종합 전형 면접을 준비하는 수험생을 위한 AI 면접코치입니다.
학생부 내용을 분석하여 맞춤형 면접 예상 질문을 생성하고, 음성 인식을 통해 실전처럼 연습할 수 있습니다.

### ✨ 주요 기능

- 🏫 **주요 10개 대학 지원**: 서울대, 연세대, 고려대, 성균관대, 한양대, 중앙대, 경희대, 외대, 서울시립대, 건국대
- 📚 **전 학과 지원**: 인문/자연/사범/예체능 (간호학과 제외)
- 🤖 **AI 맞춤 질문 생성**: 학생부 내용을 분석하여 학과별 특화 질문 생성
- 🎤 **음성 인식 연습**: Web Speech API를 활용한 실전 면접 연습
- 💡 **답변 가이드**: 각 질문별 답변 방향 제시
- ✅ **강점/약점 분석**: 학생부 기반 면접 대비 전략 제공

### 🎯 지원 대상

- 2027학년도 학생부종합 전형 지원자
- 면접이 포함된 전형 준비 수험생
- 학과별 맞춤 질문으로 연습하고 싶은 학생

### ⚠️ 지원하지 않는 학과

- **간호학과**: 별도 서비스로 제공 예정

## 🚀 사용 방법

### 1. 웹사이트 접속

**배포 URL**: [https://roche07-star.github.io/interview-coach/](https://roche07-star.github.io/interview-coach/)

**커스텀 도메인** (설정 예정): https://interview.jobizic.com

### 2. API 키 준비

Anthropic Claude API 키가 필요합니다.
- [Anthropic Console](https://console.anthropic.com)에서 API 키 발급
- 무료 크레딧으로 충분히 사용 가능

### 3. 면접 연습 시작

1. **Claude API 키 입력**
2. **대학 선택** (예: 연세대학교)
3. **학과 선택** (예: 경영학과)
4. **전형 선택** (예: 학생부종합_활동우수형)
5. **학생부 입력** (생활기록부 내용 복사/붙여넣기)
6. **분석 시작** 버튼 클릭
7. **생성된 질문으로 연습**
8. **음성으로 답변 연습** (선택)

## 🏗️ 기술 스택

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **AI**: Anthropic Claude API (Claude Sonnet 4)
- **음성 인식**: Web Speech API
- **배포**: GitHub Pages
- **도메인**: Custom domain via Cloudflare DNS

### 평가 기준 (공통)

대부분의 학생부종합 전형은 다음 4가지 요소로 평가합니다:

- **전공적합성** (30%): 지원 전공에 대한 관심과 이해
- **학업역량** (30%): 학업 수행 능력 및 탐구 능력
- **인성** (20%): 협업, 나눔, 배려, 소통 능력
- **발전가능성** (20%): 자기주도성, 창의성, 성장 잠재력

## ⚠️ 면책 사항

본 서비스는 **면접 연습 도구**입니다.

- 면접 예상 질문은 공개 자료 및 일반적인 평가 기준을 바탕으로 생성되며 실제 면접과 다를 수 있습니다.
- 분석 결과는 참고용이며 실제 입시 결과에 대해 책임지지 않습니다.
- 전형 정보는 변경될 수 있으니 반드시 대학 공식 모집요강을 확인하세요.
- **실제 면접 결과는 대학 평가위원회가 결정하며, 본 서비스는 합격을 보장하지 않습니다.**
